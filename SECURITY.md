# Security policy

Docklet Next is in early development and has no supported product release yet.

Report suspected vulnerabilities privately through GitHub Security Advisories:
open the repository Security tab, choose Advisories, then Report a vulnerability.
Use [private reporting](https://github.com/florianfinn/docklet-next/security/advisories/new).
If private reporting is not enabled, ask the maintainer to enable it in a public
issue without including vulnerability details.

Include the affected revision, impact, reproduction steps using synthetic data,
and any proposed fix. Do not include live credentials, private hosts or operational
addresses. Coordinate disclosure privately before publishing technical details.
