# Free shadcn/ui source only

Use free shadcn/ui primitives. Premium blocks may be visual references, never
copied source, structure or a parallel premium implementation. Do not configure a
premium registry or request a premium API key. This replaces the former hub's
Pro-first rule and preserves the approved prototype's free-only direction.

Record upstream paths, full revisions or content hashes, retrieval dates, licences
and deviations for copied primitives. Preserve MIT notices and verify dependencies
and fonts separately. Before publication, independent review checks that the free
components were not copied from premium source. M2 imports and maintains the
prototype free-only guard alongside its source inventory; there is no UI in M0.
